# Verity: all100 levels

100 native Roblox models, one shared sphere,16 uploaded skin textures,8 independent
existing expression images. This is a complete progression library, not100 unrelated
meshes or100 unique textures. Each level has a named model, texture/tone descriptor
and suggested gameplay scale from existing LevelConfig. Model files stay normalized
at diameter1.7; AlreadyScaled=false prevents applying growth twice.

Families:1–9original base colors;10–24Aqua;25–49Frost;50–74Magma;75–89Cyber;
90–99Cosmic;100Rainbow. Inside each family three texture stages and gentle tone
progression preserve the approved shapes without excessive stripes or extra parts.
The five original anchor levels10/25/50/75/100 keep their original uploaded textures
and neutral white vertex tint. Cosmic is now the90+family, not just an alternative.

Verity_All_100_Models.rbxmx is the whole library. models/ contains100 individual
rbxmx files. levels.json is the full manifest including family, real texture IDs,
vertex tint, normalized base size and suggested scale. Each model includes the
same8-expression registry under Integration/Emotions; Joy is the default face.

For the game use the full updated build: default.project.json already maps this
library into ReplicatedStorage.VerityElementalModels; Shared.VerityElementalSkins
and the existing Factory select the correct appearance. Growth/follow/emotion/
upgrade/spawn/cosmetics systems retain their existing owners. No new animation,
physics, economy, level curve or server requests were added.

Generated by tools/build_verity_all_levels.py; ten progression images authored by
tools/build_verity_progression_skins.py from the approved procedural recipes and
uploaded in Studio. Real upload readbacks: ../progression-skins/roblox-assets.json
and ../roblox-assets.json. No fabricated IDs. No image per level is required.

Checked with tools/check_verity_all_levels.py:100 models, unique referents and valid
Body/PrimaryPart/face contracts,16 texture IDs,8 expression entries per model,
correct shared growth values,200 actual stage-function transitions forward/reverse,
anchor preservation, invalid-level behavior. Admin/startup/audio regression checks
and complete Rojo build passed. No Play or mobile performance claim.
