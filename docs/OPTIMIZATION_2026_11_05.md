# Оптимизация и исправления — 5 ноября 2026

База: локальный merge 933da5b, включающий origin/main c21872e. Прямое поручение — оптимизировать проект и убрать ошибки. Прежний запрет на автоматические проверки, компиляцию Luau и Studio Play сохранён. Ниже — изменения по чтению исходников; это не замеры FPS и не подтверждение отсутствия всех багов.

## Клиент и интерфейс

- AbilityController обновляет кнопки на своей частоте 10 Гц, вместо каждого Heartbeat и дополнительного вызова из Main.Tick. Событийное обновление состояния при открытии меню сохранено.
- Main обновляет скрытые Verity/Workshop/Phone/Cosmetics панели при их открытии, вместо полного Render на каждый снимок. Задачи продолжают обновлять цель обучения по StateChanged даже при закрытой панели; таймеры задач рисуются только в открытой вкладке.
- Магазин способностей хранит новый state/offer, но перерисовывает 11 карточек только при открытой панели. Обработчик Visible выполняет актуальный Render при открытии.
- UIWidgets.SetButton записывает Text/Interactable/Selectable/UIState только при изменении; duration=0 в UIAnimationController устанавливает свойства сразу без Tween. Feed.FinishReveal отменяет анимацию перед окончательным размером карты.
- Уведомления: очередь хранит именованные поля (suffix больше не теряется из-за nil lifetime в table.unpack), одинаковые ожидающие сообщения не копятся, обрезка русского текста идёт по UTF-8 границе.

## Восстановление сетевых операций

CoreNetworkAdapter раньше прекращал повтор после двух попыток и оставлял интерфейс навсегда заблокированным. Теперь та же операция с тем же operationId повторяется через 8, 16, затем 30 секунд до коррелированного ответа. Используется актуальный RemoteEvent после переподключения, а не ссылка на старый экземпляр. Серверная дедупликация и монотонная последовательность сохранены; новая покупка не запускается до выяснения исхода старой.

Sync разрешён при ожидаемой ревизии snapshot (fence), но по-прежнему не обходит незавершённую покупку. Это закрывает зависание, когда результат уже пришёл, а снимок состояния задержался. После разрешения таймаута запрашивается синхронизация.

## Эффекты, стройка, физика

- VerityVisualController поддерживает список BasePart через DescendantAdded/Removing; изменение fade больше не вызывает GetDescendants каждый кадр. Tint записывается только при реальном изменении цвета.
- Аура получает Factory.Color(renderLevel). Текстурированное тело специально белое; прежде из-за чтения Body.Color аура новых форм могла оставаться белой.
- Скрытие далёкой/выключенной группы VFX выполняется один раз до её следующего показа.
- HouseConstructionController отслеживает части дома, объединяет несколько revision-сигналов в один отложенный проход, не трогает стекло WorldSurfaceController, не отменяет fade при неизменной видимости. Отмена/завершение/stream-out очищает Tween, ссылки и свои временные LocalTransparencyModifier. Уменьшение эффектов/движения завершает текущие fade.
- HouseProgression.Tick разрешает Character/Root/Humanoid один раз на игрока за проход вместо повторного поиска внутри каждого из 16 домов. Проверки запертого чужого дома и закрытого верхнего этажа сохранены.
- WatchFlightInput использует один pending watchdog на активный полёт. Последний ввод обновляет время; новые Steer-пакеты не создают каждый раз новую задачу. Таймаут не обнуляет скорость управляемой посадки/взлёта. Delayed leap дополнительно проверяет живой Humanoid в иерархии.
- Поиск и подсветка статических целей задания выполняются 10 Гц, а плавные вспышки продолжают идти по кадру. WorldSurfaceController не пишет почти неизменный LTM стекла.

## Загрузка и очистка

Галерея VerityElementalModels из 100 авторских моделей перенесена из ReplicatedStorage в ServerStorage в основном Rojo-проекте. Ссылок на неё в runtime src нет: Factory использует Shared.VerityElementalSkins и общий mesh/texture IDs. Модели остаются в Studio и репозитории, но перестают реплицироваться каждому игроку. Генератор build_verity_all_levels.py сохраняет новое размещение. Runtime-скины, эмоции и все 100 уровней остаются прежними.

Cleanup.Destroy продолжает освобождать оставшиеся ресурсы при ошибке одного callback и выводит warn, вместо остановки посередине со всеми оставшимися соединениями.

Сохранены Core-протокол, экономика, данные, цены, native prompts, PvP, паркур, доставка, верховая езда, физические двери, 32 звука и настройки языка/ReducedEffects. Не выполнялись сбросы профилей, удаление ассетов, Roblox Publish или Git push. Посторонний staged main.py не менялся.
