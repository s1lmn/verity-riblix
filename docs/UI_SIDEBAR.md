# Компактное меню слева

По прямому запросу пользователя широкие HUD и навигация заменены компактной левой панелью.
Квадратные кнопки 44–52 px используют локальные векторные иконки и короткие подписи.
На высоком экране — один столбец, на низком — два. Шесть кнопок: Verity, Phone, Tasks,
Power, Style и Settings. Деньги/доход/уровень занимают карточку 150 px, подсказка — до 190 px.
Здоровое соединение не выводит постоянную надпись. Окна появляются только по нажатию,
имеют ширину до 420 px и остаются рядом с меню; на узком экране открываются как модальные.

Проверены все шесть окон в настоящем UI и раскладка шести размеров GUI canvas, включая
размер пользовательского скриншота и узкие экраны. Кнопки квадратные, не пересекаются,
имеют цель минимум 44 px, подсказка помещается в безопасную область. Это не проверка
физического телефона. Реальные скриншоты Studio просмотрены, ошибок UI в консоли нет.

Изменены только UIBuilder, MainUIController (видимость статуса), TutorialController (текст).
Core/World/сетевой протокол не менялись. Полный игровой прогон 1/2/8 и 639 автоматических
проверок не повторялся для косметической правки; отчёты COMPLETE_* сохраняют fingerprint
базовой версии. UI_SIDEBAR_REPORT.json связывает эту базу с новой сборкой и проверкой UI.
