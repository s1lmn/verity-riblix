# Магазин — первый проход на трёх товарах

9 ноября 2026. Перед началом git fetch origin: HEAD=origin/main=09fdb4b, новых коммитов не было. Ветка agent/core. Это локальный проход для согласования стиля, без нового push/Publish/изменений в Creator Dashboard.

## Что можно посмотреть

Ещё → Магазин, три прежних раздела: Ускорение / Verity / Дом. Сцена встроена в карточку, а не открывает вторую плашку поверх списка. Кнопки минимум44px, действия48px, без увеличения за границы при нажатии. Карточка по вертикали: название → одна польза → состав/постоянное право → крупная модель → факты → цена Roblox → Примерить / Купить либо Выбрать / Выбрано. Выбранную косметику можно отдельно снять.

Весь длинный текст измеряется по выбранному RU/EN и фактической ширине, а не втискивается в фиксированные48px. Контроллер Main по-прежнему показывает одну основную панель, SHOP находится внутри Safe, закрытие возвращает в Ещё. ScrollingFrame и карточки обрезают содержимое по границам; после Примерить прокрутка ведёт к модели. Новые камеры принадлежат ViewportFrame, камера игрока не меняется. Предпросмотры не модифицируют профиль, способности, физику, глобальное освещение или погоду.

Карточка прямо говорит: этажи и доход покупаются игровой прокачкой; оформление показывается после первого строительного этапа.

## Фактическая польза героя и баланс

AbilityCatalog.homelander: полёт18с, скорость42studs/с, повтор через24с от активации (номинально6с паузы после полного полёта). Лазеры40урона за атаку, дальность140studs, перезарядка8с. Визуальная длительность эффекта1,1с; фактический урон проверяется3серверными импульсами, а не40урона каждый кадр. Эти параметры не изменялись. F/G, L1/R1, экранные действия сохранены; движение через стик/WASD, прыжок — подъём, Ctrl — спуск на ПК.

Свободный мир и обычное PvE доступны с прежними проверками. Гонки/паркур/слияние блокируют отдельные активные способности. Испытания разрешают только нужную силу, безопасные зоны защищены; дома ограничивают полёт под крышей. PvE-волны — совместный бой против NPC, не рейтинговый PvP. Существующий открытый PvP не превращён в режим равных loadout. Если нужен соревновательный PvP, Core должен вводить одинаковый ареновый набор для всех: сейчас такой режим не обещается карточкой.

Без Play нельзя заключить, что18с/40урона действительно слабы. Конкретный резервный вариант для отдельного решения Core: полёт24с/повтор30с/скорость46; лазеры56урона только по NPC, при сохранении PvP40/8с/140studs. Для рейтинговых режимов — прежние блокировки или одинаковые выданные наборы. Пока это предложение, не применённый бафф и не показанная игроку характеристика.

## ×3: проверенные исходники

Пример без построек и временных усилений на1уровне: EconomyConfig.getIncome(1)=5; за1секунду $5 → $15. Живая карточка использует текущий уровень/дом/BoostMultiplier и показывает свои значения, в пределах ограничения MaxMoney/TotalEarned. Материалы и украшения не утраиваются.

| Источник денег | Применение ×3 |
| --- | --- |
| Доход Verity, дом, дверь и второй этаж | IncomeService.Settle / EconomyService.GetPermanentMultiplier |
| Свайпы и редкость карточек | PhoneService → GetSwipeIncome → GetMultiplier |
| Поручения | TaskService → GetMultiplier |
| Уличные посылки, включая редкие денежные награды | StreetDeliveryService → GetMultiplier |
| Паркур и гонки | ParkourService / VerityRaceService → GetMultiplier |
| PvE-волны и тренировочные цели | VerityBattleService / CombatTargets → GetMultiplier |
| Искры, ритм | DiversionsService → GetMultiplier |
| События района | CommunityService → GetMultiplier |
| Денежные погодные активности/испытания | AdventureService → GetMultiplier |

AddCash сам не умножает произвольные поступления. Новые источники должны явно применять GetMultiplier, чтобы не обещать несуществующий бонус. EconomyConfig.LevelCost и MaxLevel100 не изменены, все уровни остаются бесплатными. Архивные целевые сроки прохождения не обещаются покупателю.

## Права, цена и ограничения выполнения

Сохранены8настоящих pass ID, PremiumService, PremiumGrants/PremiumLoadout, whitelist вариантов, operationId и старые сохранения. Покупки в магазине идут через прежний RequestBuyPremiumOffer; экипировка героя — существующий AbilityShop, оформление — прежние запросы. Никакой выдачи по закрытию Roblox prompt; клиентский listener только убирает ожидание. Memory не допускает реальную покупку.

Цена и IsForSale читаются на клиенте GetProductInfoAsync с настоящего pass ID, в том числе региональная цена. При неизвестной цене нет подстановки плановой; ошибка и Offsale показываются раздельно. Смена цены и включение продажи Roblox не выполнялись. Справочник: https://create.roblox.com/docs/production/monetization/regional-pricing .

Превью только у видимых карточек, максимум2мира/1на LowGraphics; при закрытии, смене раздела, варианта, размера экрана и при перекрывающей церемонии объекты уничтожаются. Анимации используют уже существующий кадровый цикл GameplayFeedback, максимум30/20обновлений в секунду; ReducedMotion/ReducedEffects оставляют статичный показ. Новых потоков игровой физики и постоянных эмиттеров нет. Ограничения ViewportFrame учтены: собственные Ambient/LightColor, native модельные лучи, без зависимости от Bloom/ParticleEmitter в витрине. Документация: https://create.roblox.com/docs/reference/engine/classes/ViewportFrame и https://create.roblox.com/docs/reference/engine/classes/WorldModel .

Прочитаны source/diff, выполняется только упаковка Rojo --no-verify. Play, тесты, валидаторы, Luau-компиляция, рендеры/скриншоты, FPS-замеры, реальные покупки и визуальная мобильная приёмка не выполнялись. Доступность кнопок, читабельность и очистка предусмотрены кодом, наблюдённый внешний вид/проходимость не заявляются. main.py остаётся staged отдельно.

## Следующий проход после согласования этих карточек

Атмосфера: участок в ночной сцене с отдельным локальным светом, не переводить общий сервер в ночь. Аура — на летящем спутнике; слияние — встреча двух шаров/сборка/след с явной подписью «Достаточно пропуска у одного»; вечеринка — танцпол и кнопка пробного конфетти, а реальный запуск — через проверку права хозяина; галерея — настоящая Feed-карта/рамка/обложка альбома. Их текущие примерки и права сохранены, новые постановочные сцены ещё не реализованы в первом проходе.
