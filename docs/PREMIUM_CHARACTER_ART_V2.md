# Тематические платные персонажи V2

10 ноября 2026. Прямой запрос пользователя: сделать платных за Robux персонажей яркими, тематическими, уникальными и необычными. Переработаны все шесть существующих образов, включая Алого стража.

| Образ | Палитра и узнаваемые детали |
|---|---|
| Алый страж | Алый/золото/малиновый, раздельный церемониальный плащ, позолоченная мантия, солнечный гребень, сегментированная корона за спиной; красные искры в глазах. |
| Рифовый капитан | Бирюза/коралл/морской синий, ветвящиеся кораллы, жемчужные бутоны, медальон прилива, раковина со спиралью на спине, плавники и плавающие жемчужины. |
| Фазовый гонец | Сиреневый/циан/розовый, угловатые векторные стабилизаторы, асимметричная антенна, маленькая фазовая посылка, вращающийся сегментированный портал. |
| Магмовый кузнец | Мандариновый/базальтовый/золотой, слоистая вулканическая корона, светящиеся трещины, медные заклёпки, печное ядро и три камня-спутника. |
| Янтарный медик | Янтарь/кремовый/мята, светящийся эликсир в ампулах, лепестки, сердечный знак, фонарь на спине, шестигранный медовый ореол с каплями. |
| Полярный следопыт | Ледяной голубой/лиловый/мятный, веера из гранёных кристаллов со светящимися прожилками, ледяная корона, шарф и маленькое северное сияние. |

Сохранена форма шара, глаза и улыбка открыты. Базовая FaceGui больше не накладывает старое общее лицо поверх тематических глаз/улыбки платного образа; у бесплатного Verity прежняя мимика сохранена. Отдельные выражения: мягкие открытые глаза медика/капитана, уверенный взгляд стража/кузнеца, ледяные блики следопыта.

CharacterPackArt — одна фабрика для настоящего спутника и 3D-примерки. Геометрия создаётся в нормализованных координатах, затем масштабируется родителем вместе с ростом Verity. Нет внешних ID, текстур, Meshy/Blender-ассетов, физики или коллизий декора. Не требуется публикация новых ассетов.

Малые локальные группы оживают через существующий Tick VerityVisualController / StepCharacter магазина, с ограничением 30 Hz. Нет нового RunService, не создаются части в кадре, нет дополнительных ParticleEmitter/PointLight/Highlight. При низкой графике, Reduced Effects/Motion, удалении или церемонии геометрия остаётся в спокойной позе. Motion-handle хранится существующей записью спутника/сцены и заменяется с Cosmetics; уничтожение модели/сцены очищает сами детали. Камера примерки расширена с учётом верхних деталей и полётной демонстрации.

Существующие ID наборов/пропусков, права владения, выбор образа через способности, бонусы, цены, урон и длительности не менялись. Текущий main перед работой: d3c2761. main.py исключить из коммита.

Выполнено только чтение исходников/diff и упаковка --no-verify. Без Play, тестов, компиляции, валидаторов, рендеров, скриншотов, FPS-профилирования и Roblox Publish. Красота, посадка всех комбинаций аксессуаров, все масштабы и мобильная производительность не подтверждены игровым прогоном. Автопуш разрешён пользователем.

Справочник используемых API: https://create.roblox.com/docs/reference/engine/classes/Model и https://create.roblox.com/docs/reference/engine/classes/PVInstance.
