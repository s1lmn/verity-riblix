# Остановка запуска: HomeStyleService до HouseProgression

8 ноября 2026. Пользователь сообщил о незапуске/долгой загрузке после этапа дома и общего события.

## Подтверждённая причина

Прочитан Output уже открытой Studio VERITY-Latest.rbxlx через read-only get_console_output. В пользовательских попытках запуска повторяется HomeStyleService:13: attempt to index nil with plots; вызывающий ServerBootstrap:173. Это ошибка нашей интеграции: HomeStyleService.new проходил world.houseProgression.plots, но World.houseProgression создавался ниже, приблизительно на строке240. Bootstrap завершался до установки CoreReady, регистрации участников и загрузки профилей. Ожидание клиента не могло это исправить. Сообщения BuiltInStandalone Assistant/DeviceSimulatorToolbar встречаются рядом, но не являются основанием этой игровой ошибки.

## Изменение

HomeStyles объявлен заранее и создаётся непосредственно после HouseProgression.new. Инициализация служб завершена до Runtime.Services и подключения игроков/Heartbeat. Не подменять реестр пустой таблицей и не скрывать ошибку через фиктивный успешный startup.

Новые опциональные VerityBond и VerityCommunity подключаются на клиенте через FindFirstChild/ChildAdded вместо последовательных WaitForChild10. Отсутствие этих endpoints не задерживает основной интерфейс и старт CoreNetworkAdapter. Соединения освобождаются при смене remote и уничтожении контроллера.

ReplicatedStorage.VerityCoreReady отражает достижение существующего CoreReady на сервере. Если за20с этого не произошло, VersionController выводит понятное сообщение о незавершённом старте, а не оставляет только бесконечную загрузку. При поздней готовности сообщение сбрасывается. Это сигнал состояния, не восстановление упавшего сервера и не замер реального времени загрузки.

## Что действительно проверено

Прочитан уже существующий журнал пользователя, затем исходники и порядок зависимостей. Выполнена только упаковка --no-verify. По действующему запрету не запускались Play, тесты, валидаторы, компиляция Luau или визуальная приёмка. Успешный повторный запуск ещё не наблюдался. Открытая в Studio старая модель не редактировалась; для применения нужно открыть новый файл сборки. Нового push/Roblox Publish нет. Все предыдущие игровые правки и сторонний staged main.py сохранены.
