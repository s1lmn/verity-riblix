# Стрелки и понятное обучение

Первые действия объясняются по-русски, по одной цели за раз: коробка → телефон →
первые деньги → покупка уровня. После этого подсказки ведут к выбранному заданию.
Состояние берётся из подтверждённого снимка Core; клиент не выдаёт награды и не
пропускает обучение по таймеру.

У мировой цели есть личный маркер, контур и стрелка-компас в компактной карточке слева.
На полу показываются до восьми стрелок по реальному маршруту PathfindingService,
с учётом дверей, лестницы и препятствий. Сначала ищется маршрут без прыжков, затем
при необходимости доступный маршрут с прыжком. Габариты берутся из параметров персонажа.
После резкого переноса и респавна старый маршрут сбрасывается. Если путь не найден
или не загружена геометрия, остаются указатель и метка; прямой ложный путь через стены
не рисуется. Расчёт ограничен по частоте, видимая геометрия существует только у клиента.

Рядом с коробкой/кнопкой появляется точное действие для клавиатуры, touch или gamepad.
Действие не предлагается через стену. В интерфейсе подсвечивается нужная кнопка,
появляется указатель; при необходимости окно прокручивается к кнопке. В узком окне
инструкция показывается под заголовком панели, а не закрывает её отдельной карточкой.
После выбора задания окно автоматически закрывается, после серверной выплаты метка исчезает.
Подписи игровых точек видны только вблизи, чтобы не перекрывать друг друга издалека.

PlayerStateUpdated получил дополнительное поле DeliveryPosition: Vector3 собственного
участка. Новых запросов/доверия координатам клиента нет. Сохранения и экономика не менялись.
Существующий TutorialController владеет единой навигацией; старая вторая стрелка Tasks удалена.

Проверки: 661 утверждение CLI, включая 22 сценария выбора цели. Реальный Studio-сценарий
сначала переносит персонажа наверх дома, затем он физически идёт по найденному пути вниз
и через дверь. Далее настоящие распаковка, свайпы/доход и первый купленный уровень;
путь к трём заданиям, их серверное завершение, перезагрузка UI и респавн. Тестовые деньги
и уровни не добавляются. Начальная позиция и короткие стартовые позиции перед заданиями
задаются только в отдельном тестовом сценарии. Результаты: GUIDANCE_SINGLE.json (17)
и GUIDANCE_MULTIPLAYER_2.json (25). Последний также проверяет личные цели двух игроков.
Физические телефоны/gamepad и облачные сохранения этим прогоном не проверялись.

В ходе проверки исправлен сброс старого пути после переноса; тестовый водитель маршрута
также использует шаг физики для клиентов Studio без активного рендера. В обычной игре
нет автоматической ходьбы, нажатия кнопок, распаковки или покупок.

API пути: https://create.roblox.com/docs/characters/pathfinding
