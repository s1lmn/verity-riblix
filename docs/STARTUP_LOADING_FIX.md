# Загрузка прогресса: исправление остановки сервера

5 ноября пользователь сообщил, что последняя сборка остаётся на загрузке. Прочитан существующий Output подключённой Roblox Studio VERITY-Latest.rbxlx. Studio находилась в Edit, Play агент не запускал.

В журнале повторяется: ReplicatedStorage.World.VerityBattleBuilder:28: Malformed string; did you forget to finish it? Затем Requested module experienced an error while loading, ServerBootstrap line 126.

Причина: добавленная подпись арены содержала настоящий перенос строки внутри короткой строки в двойных кавычках. Это синтаксическая ошибка Luau, останавливающая require до привязки жизненного цикла игроков. Клиентский экран оставался без серверного состояния. Никакие профили не сбрасываются.

Исправление: в подписи используется экранированный перенос \n. Исправлен репозиторий, обновляется Latest и такая же исходная строка в уже открытом Edit DataModel. Только чтение прежних логов и правка исходников; нет тестов/валидаторов/компиляции/нового Play. Успешный новый запуск пока не наблюдался. Push не выполнялся.
