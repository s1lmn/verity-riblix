# Предрелизный этап — разработчик 1 (Core / Logic)

Основа: agent/core, HEAD 87e95d8. Изменения этого этапа локальные. Исходный main.py пользователя не включён в работу. Сохраняется локальное исправление строки в VerityBattleBuilder из STARTUP_LOADING_FIX.md.

## Что реализовано в исходниках

- **Битвы:** один серверный mover на Heartbeat, решения о цели раз в .15 с; положение и поворот через Shared.EnemyMotion. Тот же Sample используется для актуализации hitbox перед raycast. Поворот ограничен долей .65 за сегмент. Перед ударом траектория останавливается, StrikeTarget остаётся неизменной точкой предупреждения. EnemyDead отключает query, прежнее исчезновение .65 с сохранено. Finish переводит раунд в Results до выдачи наград. Новые пакеты VerityEnemyMotion предназначены разработчику 2; второй серверный контроллер не создан.
- **Доставка:** сервер выбирает тип награды при Start один раз. 70% Cash×1, 22% Cash×2, 6% Cash×5, 2% украшение. Основа без изменений: 15 секунд базового дохода текущего уровня × существующий денежный множитель. Платные множители не меняют вероятность. Кандидат косметики определяется зафиксированным случайным числом из ещё не полученных предметов.
- **Украшения доставки:** delivery_cap / delivery_goggles / delivery_wings (Head / Face / Ears) в прежнем CosmeticCatalog/инвентаре. Начальная native-геометрия уже позволяет их носить. source=StreetDelivery, exclusive=true; нельзя назначить продажу Developer Product. Другие активности не выдают эти ID. Если все три уже есть — компенсация **×5** обычной денежной основы (явное начальное решение для балансировки).
- **Однократность посылки:** проверки профиля/персонажа/сессии/дистанции/LOS/времени; блокировка до синхронной выдачи, второй Trigger ничего не выдаёт и не перевыбирает. Получение несовместимо с гонкой, паркуром, ареной и ездой. Полученный ID сохраняется через существующие CosmeticsOwned и session-lock/autosave/release. Нет нового DataStore и отдельного claim remote. Постоянная запись в настоящем DataStore ещё не проверена.
- **Прогрессия:** серверные Progression и NextUnlock: коробка → первый заработок/улучшение → одно задание PRESS_BUTTON → свободная игра. NextUnlock сообщает требование, прогресс и остаток до доступной покупки способности либо следующего значимого уровня/облика/езды. Достижение уровня никогда не выдаёт купленную способность. Езда остаётся постоянным открытием реального 50 уровня; ранней выдачи нет.
- **Сохранение обучения:** добавлен только boolean FirstActivityCompleted (по умолчанию false), совместимое дополнение DataVersion=2. Старые деньги/инвентарь/экипировка не заменяются. Возвращающемуся игроку без поля предлагается одна активность; после её успешного завершения предложение не возвращается при обычном сохранении.
- **Способности:** AbilityCollection передаёт LockedLevel / Purchasable / Owned / Equipped; premium — PassRequired / Unavailable. Отдельно owned/levelMet/affordable/canBuy/canEquip, стоимость, требование, описание, иконка и доступные слоты. HeroPassOwned только после настоящей проверки Marketplace, сохранённый выбор premium не доказывает право владения. Настоящие ID пропусков по-прежнему не подключены по решению пользователя.
- **Слоты:** AbilitySlots.Mobility / Attack с серверными выбранной силой, F/G, L1/R1, readyAt/activeUntil, временным импульсом арены, пустым состоянием и причиной блокировки. Гонки и паркур запрещают обе активные категории. RequestEquipAbility принимает необязательный slot; сервер проверяет соответствие, владение и уровень. Старые вызовы сохранены, bundle по умолчанию занимает оба слота.
- **Паркур:** сохранены 48 платформ, 6 секций, порядок, checkpoints/reset/exit. В секциях 5–6 добавлены sweep/pulse сочетания. Каждая ловушка имеет безопасное окно и предварительное предупреждение (1.4 с в ранних секциях, 1.2 с в последних); sweep неподвижен на предупреждении. HazardGeometry/HazardHits согласуют размер/угол видимой полосы с областью касания тела. Прогресс требует приземления возле поверхности, а не касания широкой невидимой области в воздухе. Разные пассивные speed/jump форм сохранены; активные силы отключены на всём маршруте.
- **Награды активностей:** ActivityRewards — единая формула для UI quote и фактической выдачи. Parkour: max(60s income, min(8% next cost, 240s income)); Battle: max(55s, min(10%,300s)); Race: max(12s,min(1.5%,60s)). Затем прежний boost/pass; медаль паркура ×1/1.25/1.5. На 100 уровне остаётся награда за секунды дохода. Районные задания масштабируются по базовому доходу с прежней минимальной суммой. Доставка сохраняет свою исходную формулу. Cooldown и бесплатное участие сохранены.
- **Минимальная клиентская совместимость:** адаптер не теряет deliveryReward; уведомление называет конкретный предмет/множитель/компенсацию; редкий приз использует существующий Milestone25 вместо обычного звука подбора. Новых аудио ID и фоновой музыки нет. Действующий Tutorial получил одну рекомендацию первого задания, второго окна нет. UIModel принимает завершённый TutorialStep=7.
