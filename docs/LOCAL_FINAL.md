# Локальная итоговая интеграция VERITY

Полученный remote baseline: 9bc6d2d. История локального Core объединена с World v5,
клиентским UI и анимациями. Никакие изменения на GitHub не отправляются.

## Разрешённые конфликты

- Сохранён прямой выбор пользователя 5×. LevelConfig объединяет функции Core и метаданные UI.
- Убрана схема отдельных персональных комнат: вход в открытые физические дома, гости разрешены.
- Один серверный bootstrap включает Core и World; UI/world-client запускаются на клиенте.
- Согласованы версии пакетов, имена действий, numeric operationId, поля телефона/заданий и результаты.
- Визуализатор получает реальные серверные события и tagged-модель после распаковки.
- Общая Verity приведена к референсу шарика без ушей/лап; первые 10 арт-прототипов изолированы.
- Итоговый place исключает тестовые мосты, фикстуры и галерею. Модели 11–100 не генерировались.

покупок и 99 анимаций до 5×; телефон/повтор запроса/три физических задания, вход через проём,

Файл: FINAL_SINGLE_REPORT.json. Многопользовательские результаты — FINAL_MULTIPLAYER_*_REPORT.json.

## Границы результата

Это локальный игровой прототип с объединёнными компонентами, не опубликованный релиз.
Studio Memory не сохраняет прогресс между Play-сессиями. Реальный DataStore на опубликованном
тестовом place, 16/24 клиента, физические мобильные устройства и 10-минутный FPS-профиль
не проверены. Нет настроенных платных товаров или выдуманных Audio AssetId.
Геометрические варианты всех шести стадий домов не были переданы; HouseTier подтверждается
Core и виден в UI, текущий физический дом остаётся утверждённой моделью World.
Музыка/эффекты без разрешённых общих AudioConfig остаются безопасно беззвучными.
Баланс 24h/3.75h — детерминированный кандидат, не доказанная длительность реальной игры.

Запуск: открыть build/VERITY-Final.rbxlx в Studio, Play. Исходный проект — default.project.json.
Исторические отчёты предыдущих приватных интерьеров и 15× UI не являются доказательством
для этой версии. Их не переписывали под новый результат.

Многопользовательские Studio-запуски: 2 игрока — 29 утверждений; 8 игроков — 71.
Все три итоговых отчёта содержат fingerprint проверенных производственных исходников.
