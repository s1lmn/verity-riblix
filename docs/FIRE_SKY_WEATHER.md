# Огненное небо — 8 ноября 2026

По запросу пользователя добавлена пятая, фантастическая погода Fire: «Огненное небо» / Ember skies. На новом сервере первое событие начинается через30с и длится110с. Актуальный цикл: ясно30 → Fire110 → ясно45 → Stars135 → ясно60 → Storm95 → Rainbow180 → ясно60, затем повтор.

WeatherVisuals использует прежний ограниченный пул: багровые облака, тёплый вечерний свет, красно-золотые метеоры (24слота на высоком качестве,10среднее,2низкое), до64восходящих угольков и четыре широкие светящиеся ленты над районом. Под крышей близкие угольки скрываются по кэшируемому лучу. ReducedMotion/ReducedEffects убирают быстрые метеоры и ленты, оставляют спокойные угольки; LowGraphics снижает число угольков до10. Все эффекты косметические: нет случайного урона, пожара/разрушения домов, изменения владения или покупок. Прежний владелец Lighting/cleanup/frame loop сохранён, новых эмиттеров/звуков/музыки нет.

Обсерватория погоды запускает охоту за пятью солнечными угольками. Переиспользуются10точек небесных находок, которые во время Fire меняют цвет и подписи; личный порядок, жёлтая навигация и native prompts остаются. Kind Stars — внутренний тип общего поиска, id Fire/Stars различает реальные погодные раунды. Сервер проверяет погоду, раунд, текущую цель, близость, живого персонажа и частоту взаимодействия. Fire/Stars имеют отдельные карты однократной выдачи по UserId/раунду; повторный вход в тот же сервер не даёт новый грант.

За сбор выдаются деньги по ActivityRewards.Fire (75секунд базового дохода, targetfraction .12, cap240) с серверными множителями и home_ember_lantern. Жар-светильник хранится в прежнем CosmeticsOwned без новых полей/миграций, появляется после этапа стройки2. Девятый приз размещён на втором ряду настенной полки, чтобы не пересечь боковую стену и прежние награды. Его модель — неоновое огненное ядро в рамке с золотыми крышками. Добавлены русские/английские подписи и карточка события.

Выполнены изменения исходников и упаковка --no-verify. По действующему запрету не запускались тесты, валидаторы, компиляция Luau, Play, рендеры и визуальная приёмка.
