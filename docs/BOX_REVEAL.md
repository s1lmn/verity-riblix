# Первое появление Verity

Клиентская церемония начинается только по подтверждённому Core VeritySpawned своего
владельца, рядом с CoreDeliveryBox своего участка. Core по-прежнему один раз открывает
коробку, сохраняет VerityUnlocked и создаёт единственного спутника. Серверная логика,
деньги и сохранения не менялись; проигрывание эффекта не выдаёт наград.

## Хореография

Общая длительность5.03 с под загруженный BoxCeremony из V3:
- 0–~1.0: игрушечная коробка жёлтого/розового цветов шевелится;
- ~0.55–2.31: нарастают свет, цветные лучи и звёзды, открываются две створки;
- 2.31–2.63: появляется настоящее тело/лицо Verity над коробкой;
- 3.05–4.50: спутник плавно возвращается в существующий полёт за игроком;
- к5.03: коробка, лучи и блёстки исчезают, временные объекты удаляются.

Shared.VeritySpawnProfile задаёт чистую временную шкалу. World.VeritySpawnVFX владеет
только локальной декоративной коробкой/светом/звёздами (66 частей, один PointLight,
одна активная церемония на клиент). Серверный box временно скрывается через
LocalTransparencyModifier, исходное значение восстанавливается при любом завершении.
Скрипты/ProximityPrompt из Core не клонируются. Части Anchored, без коллизий/touch/query.
Геометрия домов/карты не менялась. Камера и управление остаются у игрока.

Единственный VerityVisualController остаётся владельцем позы, масштаба и видимости
настоящего спутника. Spawn mask объединяется с camera/growth visibility и скрывает
тело, лицо, label и украшения до раскрытия. Регистрация модели во время церемонии
сразу применяет текущую маску. Апгрейды из ledger ждут завершения раскрытия.
Первое появление не создаёт второго renderer/спутника. Profile заканчивается точным
масштабом1; рост и итоговый уровень по-прежнему принадлежат LevelConfig/Core.

GameplayAudioController выбирает один BoxCeremony вместо VeritySpawn и отдельных
BoxRustle/BoxAnticipation: наложения полной церемонии с её частями нет. Если коробка
не загружена или владелец далеко, длинный эффект не запускается, звучит короткий Spawn.
Отмена прерывает BoxCeremony; музыка №23 по-прежнему отсутствует.

## Отмена и доступность

Смерть/смена персонажа, смена участка, удаление привязанного спутника, расстояние>60
studs и Destroy отменяют эффект, чистят декор и освобождают видимость/звук.
Повторный eventId отсеивается; VerityBoxRevealSeen на LocalPlayer сохраняется при
пересоздании UI. Восстановленный snapshot не запускает церемонию. Reduced Motion
убирает тряску, масштабный pop и постановочный перелёт; остаются раскрытие/плавная
видимость. Reduced Effects/Reduced Motion выключают свет, ядро, лучи и звёзды.

Игрок, уже открывший коробку, не увидит церемонию при обычном перезаходе — это первый
unlock, не анимация каждого входа. Реальные сохранения для проверки не сбрасывались.

## Проверки

Компиляция91 исходника, SpawnProfileTests (границы фаз, маска, Reduced Motion,
точное завершение), регрессии существующего upgrade-профиля и check_audio.py
(в том числе выбор ceremony/fallback, отмена звука) прошли. Полная Rojo-сборка
outputs/Verity_Game_Box_Reveal_v1.rbxlx создана. Это проверки исходников/чистой
хореографии с подставными сервисами, не Studio Play, не проверка изображения/FPS.
По действующему указанию Play не запускался. Визуальную доводку проводить после
просмотра пользователем нового первого открытия коробки.
