# Игрушечный планшет заказов

TASKS оформлен в стиле утверждённого телефона: фиолетовый пластиковый бортик,
кремовая основа, жёлтый зажим и три белые карточки с нативными геометрическими
иконками. TaskTabletSkin строит GUI, UIBuilder подключает его через прежний refs.
Нет новых asset IDs, серверных механик, заданий или владельцев навигации.

Карточки показывают отдельную серверную награду и состояния «Можно начать»,
«Выполняется», «Снова через Nс». Активная кнопка закрывает меню и оставляет
существующую навигацию. TaskStart использует стабильный ключ TASKS при закрытии,
без перевода внутреннего идентификатора. При отсутствии snapshot награда сбрасывается.

Размер до420×640; небольшой экран использует вертикальную прокрутку без уменьшения
кнопок ниже44px. Сохранены SelectionGroup/Stop и общий UI animator/Reduced Motion.

Проверки: tools/check_task_tablet.py исполняет реальные Skin/Widgets/Controller
с подставными engine values: export, constructor, refs, пять размеров экрана,
скролл до третьего заказа, hit targets, награды, active/cooldown/offline/нет snapshot,
закрытие после подтверждённого TaskStart. Также прошли check_phone_skin,
check_feedback_startup, компиляция108 Luau и полная сборка.
Это проверки кода, а не визуальная приёмка Studio. Play не запускался по запросу пользователя.
