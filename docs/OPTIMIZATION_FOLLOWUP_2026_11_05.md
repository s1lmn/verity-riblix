# Дополнительные исправления — 5 ноября 2026

Продолжение OPTIMIZATION_2026_11_05.md по запросу «посмотри что ещё можно пофиксить или оптимизировать». Все предыдущие локальные изменения сохранены. Это работа по исходникам без автоматических проверок, компиляции Luau, профилирования или Studio Play.

1. **Незавершённые UI Tween.** UIAnimationController теперь слушает Destroying только для активной анимации и освобождает Tween, goal и соединение при удалении объекта. Соединение также отключается при завершении/отмене/Destroy контроллера. Раньше уничтоженная карточка или её эффект могли оставаться ключом в tweens/goals до уничтожения всего интерфейса.
2. **Телефон при смене размера/быстром закрытии.** Анимация открытия отменяется до нового layout и при закрытии телефона, Rotation сбрасывается. Старый tween больше не продолжает тянуть панель к координатам предыдущего размера экрана.
3. **Запоздалые предложения Game Pass.** Hero/×3 запоминают запрошенный ID и принимают цену только для текущего ID и живого контроллера. Изменение/удаление ID сразу очищает прежний offer/prompt state. Реальные ID по-прежнему не подключены по решению пользователя; автоматической покупки нет.
4. **Магазин косметики.** Ответ GetProductInfoAsync проверяет тип/жизнь контроллера; полученная цена обновляет открытую панель сразу. Preview WorldModel и Camera имеют Cleanup-владельца.
5. **Защита подготовки сохранения.** SaveAsync оборачивает копирование/валидацию snapshot в pcall. При ошибке снимает Saving, запрещает дальнейшие изменения и возвращает INVALID_PROFILE. Невалидная запись не отправляется в DataStore; старое сохранение не заменяется и не сбрасывается.
6. **Закрытие сервера.** Прежний одиночный flush заменён обходом до того же 25-секундного deadline: по одному активному release на профиль, ожидание существующего Save/Release, повтор не раньше чем через секунду, подбор поздно завершившихся загрузок. До начала flush рассчитан доход, затем профили Closing. Используются прежние session lock, LastRelease и UpdateAsync без обхода владельца. Если deadline истёк, выводится честный warning о неподтверждённых профилях. Постоянный отказ DataStore всё ещё не позволяет гарантировать сохранение.
7. **Полёт верхом.** Таблица seen переиспользуется вместо новой каждый PreSimulation. Частицы/Trail очищаются при переходе в ReducedEffects, вместо Clear каждый кадр.
8. **Замена RemoteEvent.** CoreNetworkAdapter хранит реальные соединения по экземплярам; удаление remote сразу отключает его слушатель и убирает ссылку. Отложенное событие от старого remote игнорируется. Перепривязка папки также очищает оставшиеся слушатели. Повтор запросов с тем же operationId и fence-синхронизация первого прохода сохранены.

Изменены только исходники/документация и локальная Rojo-сборка. Нет Git push, Roblox Publish, сбросов данных или новых цен. Пользовательский staged main.py не менялся. Реальные проверки удержания памяти, поворота телефона, смены remote, повторов сохранения и поведения на 16 игроках не выполнялись. Нельзя считать это подтверждением отсутствия всех ошибок.

Документация API: https://create.roblox.com/docs/reference/engine/classes/Instance#Destroying и https://create.roblox.com/docs/reference/engine/classes/DataModel#BindToClose.
