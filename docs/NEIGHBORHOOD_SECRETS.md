# Секреты района и способности для исследования

8 ноября 2026. Пользователь выбрал два направления: скрытые места/головоломки с украшениями и полезные для исследования способности. Реализованы три разных секрета в свободной полосе у начала района; новые площадки внутри существующего ограждения, без перестройки домов или расширения островов.

## Солнечный архив

Координаты задаются SecretsConfig.Solar (-100, .5, -RoadHalfLength-22). Физическая скрытая комната с дверью, полками и сундуком. Сначала запитать приёмник: настоящий серверно подтверждённый laser из eye_laser/homelander с проверкой направления, дальности и прямой видимости. Альтернатива без способности — три ручных заряда через native prompt с задержкой. Затем три символа: солнце → луна → звезда; на табличке та же подсказка. Неверный порядок сбрасывает только эту последовательность, без списания денег.

Лазер использует существующий VerityAbilityService, его владение/слот/cooldown и Attack VFX; попадание в механизм не выдаёт боевой награды и не наносит урон персонажам. Секретные зоны — sanctuaries для PvP; механическое попадание разрешается отдельно до защитной проверки атаки. У дома по-прежнему нельзя причинить урон игрокам. Нельзя включать механизм по клиентскому сообщению о попадании.

Дверь физически общая: открывается после решения, не захлопывается при живом игроке внутри, есть внутренняя кнопка выхода. Право на сундук личное: проход вслед за другим игроком не выдаёт украшение. Повтор символов открывает дверь снова, если она закрылась. Полноразмерный большой Verity парит над архивом через прежний follower.

Награда: prism_specs — призматические очки, Face.

## Тайник в кроне

Высокое дерево справа у начала района. Шесть ступенчатых ветвей/площадок, подъём на24studs. Обычные прыжки дают альтернативный путь; leap/flight позволяют сократить подъём. На верхней площадке нужно сыграть три колокольчика: лист → капля → солнце, затем открыть сундук. Сервер проверяет близость и опору над верхней физической площадкой. Есть спуск через native prompt без штрафа.

Награда: leaf_crown — венок хранителя кроны, Head.

## Облачная обсерватория

Начало — native prompt на взлётной площадке. Нужен выбранный обычный Небесный полёт (уровень15, $9000 за игровую валюту) либо уже реально принадлежащий/выбранный полёт героя. Пропуск по-прежнему не подключён: никакого бесплатного premium-владения или обязательной покупки Robux. Полёт верхом не считается обычным полётом этого маршрута.

Три воздушных кольца по порядку, окно90с. Сервер проверяет действующий flight в существующем AbilityService, исходного персонажа, последовательность, сегмент перемещения/радиус и разумный шаг движения; клиент не отправляет checkpoint. Последнее кольцо выше и вне посадочной платформы, чтобы не вести сквозь её пол. Над площадкой после всех колец обычный полёт отключается и персонаж приземляется. Сундук требует законченные кольца и физическую площадку под игроком. Есть возврат на землю. Воздушные стрелки рисует тот же TutorialController его прежним пулом, без второго владельца навигации и без Pathfinding к летающей точке.

Награда: cloud_charms — облачные подвески, Ears.

## Архитектура и UX

Shared.SecretsConfig, World.SecretsBuilder, Core.SecretsService и client.SecretsController. SecretsService создаётся после всех используемых Abilities/ActivityRewards/Bond и после HouseProgression/HomeStyles, до CoreReady/регистрации игроков. Подключение UI не блокирует старт: FindFirstChild/ChildAdded с cleanup. Серверный remote принимает только Sync/Select/Clear; награда не является remote-действием. Механизмы/пазлы/сундуки используют native server prompts, авторитетные дистанции и живого владельца профиля. Один реестр records, прежний общий .15 tick, публикация фокуса .5с; нет нового Heartbeat или RenderStepped.

Кнопки трёх секретов находятся в существующем меню Verity, показывают счёт0/3. «Как получить» соответствующего украшения в коллекции включает маршрут. Маршрут можно отключить крестиком; начало обычного задания также его отключает, Clear снимает воздушную попытку. Если для полёта пока не хватает уровня/денег, показаны требования и обычная навигация заработка/роста остаётся доступной. Все цели передаются позициями независимо от streaming. Ошибки последовательностей дают конкретные подсказки, повторные находки не платят наград.

ActivityRewardService.Grant сохраняет украшения в прежнем CosmeticsOwned и даёт обычный reveal с возможностью надеть. Rewards.Items расширен отдельными secret_*; Rewards.Order остаётся прежним списком трёх домашних трофеев, поэтому шкаф трофеев не ломается и не рисует секретам титанов. Подпись reveal для секретов говорит о коллекции. Никаких новых полей DataStore/валют/покупок попыток. Прогресс пазлов и колец — только текущий заход/персонаж, очищается при смерти/выходе; найденные украшения сохраняются обычной системой. Иконки/геометрия украшений без загрузки новых assets, русский/английский через общий LocaleText. Фоновая музыка не включалась.
