# WORLD / UI / VFX — передача разработчику 1

Представление WORLD / UI / VFX объединено с предрелизным Core из `main` на `8b9c885`. Сервер определяет попадания, фазы, победителей, владение и награды. Клиент показывает эти данные и рисует эффекты.

Для прицеливания по копии берётся центр серверного тела. Предупреждение использует серверную цель удара, побеждённый враг затухает. | Визуальная копия без столкновений и запросов, серверное тело и проверка препятствий сохранены. ## Используемые серверные контракты

1. **Противники.** `VerityEnemyMotion` передаёт сегменты с `enemyId`, `sequence`, `from`, `to`, `startedAt`, `duration`. Клиент и сервер используют `EnemyMotion.Sample` с серверным временем. Предупреждение привязано к `StrikeTarget`, `StrikeAt` и `EnemyRadius`. `EnemyDead` запускает затухание, удаление модели очищает представление.
2. **Паркур.** Обе стороны используют `ParkourConfig.HazardGeometry(index, serverTime)`. Фаза 0 означает безопасность, 1 предупреждение, 2 активную ловушку. Сервер применяет штраф и обрабатывает чекпоинты.
3. **Уличная посылка.** `STREET_DELIVERY_REWARD.deliveryReward` даёт атомарный результат победителя. При подходе виден локализованный `RewardDescription_ru/en`: 70% обычная выплата, 22% двойная, 6% ×5, 2% украшение. Для полной коллекции действует серверная компенсация ×5. Сохранены `delivery_cap`, `delivery_goggles`, `delivery_wings` и их слоты. Владение берётся из серверного снимка.

Для релизной приёмки нужен совместный проход нового и возвращающегося игрока, двух игроков одновременно и телефона. На этапе объединения доступен разбор исходников и упаковка Rojo с `--no-verify`. Play, тесты, компиляция и замеры FPS в этом проходе не выполнялись.
