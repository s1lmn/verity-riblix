# Стабильный текст двери и светлые кнопки улучшений

10 ноября 2026. Пользователь сообщил о мигании кнопки открытия двери и уточнил: не чёрными должны быть именно кнопки улучшений.

В исходниках найден конфликт: PurchasePadController каждые 0,1 с задавал свой ActionText, а Locale.TrackWorld сразу возвращал строку из серверных locale-атрибутов. Удалено клиентское перезаписывание. Текстом двери владеет серверная локализация; источники RU/EN «ОТКРЫТЬ ДВЕРЬ» / «ЗАКРЫТЬ ДВЕРЬ» уже существуют. UIOffset записывается только при изменении состояния покупки/управления. При открытых reward overlay площадки также недоступны.

Круглые кнопки улучшений теперь со светлым лавандовым основанием, голубым центром и мятным значком. Карточки над ними светло-голубые с тёмно-синим текстом и контрастными ценами; зелёные/красные индикаторы достаточности средств сохранены. Купленные площадки по-прежнему скрываются. Дверь и остальные ProximityPrompt остаются стандартными, без новой custom-E кнопки и без второго контроллера ввода.

Серверный CanUseDoor, собственность, дистанция, блокировка гостей и внутренний выход не менялись. Новый UI магазина из 41f8fa2 сохранён. main.py исключён из игровой работы. Пользователь ранее разрешил автопуш каждого готового апдейта.

Только чтение исходников/diff и упаковка --no-verify. Без Play, тестов, валидаторов, компиляции, рендеров и Roblox Publish. Устранён найденный конфликт кода; отсутствие других причин мигания и внешний вид в игре не подтверждены.
