# Паркур района — версия1

По следующему этапу согласованного плана добавлен необязательный маршрут.
Он расположен на боковом островке X170..282,Z230..370, соединён дорожкой вдоль
Z300 с южной частью главной дороги. Участки/дома v5 и арена Z333,X±42 не менялись.
Основа островка стыкуется с Ground по X170; дорога приподнята, coplanar-полов нет.
Геометрия рассчитана на текущий район16участков, без изменений MapRecipe/интерьеров.

13крупных studded-платформ, старт и золотой финиш, промежуточные чекпоинты4/7/10.
Краевой горизонтальный разрыв≤3.5studs, подъём≤1.5studs: геометрические условия
обычного прыжка без купленных сил; это расчёт, а не Play-подтверждение проходимости.
Способности доступны для прохождения. Номера/флаги учат маршруту, нет второго
владельца стрелок/tutorial. Новых uploaded assets/мешей/музыки нет.

ParkourBuilder идемпотентно добавляет модель как в новую, так и в существующую v5.
ParkourService подключён один раз из Core. Начать можно после распаковки Verity.
Server Touched проверяет живого владельца Character, профиль/сессию, положение Root,
следующий индекс и время2..180s. Все платформы надо пройти по порядку. Нет Remote
«выдать награду». После падения на землю в зоне маршрута игрок возвращается к
последнему флагу; перед переносом существующая сила останавливается и скорость
сбрасывается. Выход из зоны/смерть отменяет маршрут; чекпоинты не сохраняются в профиль.
Есть prompt выхода у старта и возврата к началу у финиша с проверкой расстояния.

Награда —20s базового income текущего уровня×существующий earning multiplier,
через прежний EconomyService.AddCash. Cooldown90s хранится в текущей серверной
сессии и переживает смерть, но не новый сервер. Во время cooldown маршрут остаётся
для тренировки без оплаты. Сначала блокируется повторная выдача, затем меняются
деньги/публикуется snapshot/уведомление с eventId. Проверки порядка/времени/позиции
и cooldown ограничивают выдачу; это не заявление о полной защите от teleport-cheat.

Один TaskCheckpoint звук по подтверждённому чекпоинту; один TaskCompleted по
финишу. Main не дублирует Reward SFX, но показывает фактическую полученную сумму.
Используются существующие remotes/notification/audio-контроллеры. Tick на0.15s
переиспользует существующий heartbeat, объём до16активных игроков.

Проверено tools/check_parkour.py: исполнение настоящих Builder/Service с подставными
engine values,13платформ/ограниченный part budget/anchoring/idempotence, bounds
обычных прыжков, ordered/no-skip, падение/чекпоинт, reward/dedup/cooldown/practice,
смерть/выход/позиция/unlock. --export сохраняет visual-only native asset из данных
реального Builder (без bindings/prompts/rewards; не импортировать второй раз в игру).
Дополнительно прошли ability/motion,100моделей,feedback startup/audio, compile,
полная Rojo-сборка. Play/фактическая проходимость/мобильный FPS не проверялись.

Основная сборка: outputs/Verity_Parkour_v1.rbxlx в рабочей папке чата; просмотр
геометрии отдельно: outputs/Verity_Parkour_Visual_v1.rbxmx. Код пока локальный.
