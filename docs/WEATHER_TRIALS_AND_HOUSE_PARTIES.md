# Погода, испытания способностей и вечеринки — 8 ноября 2026

## Реализовано в исходниках

AdventureConfig/Builder/Service/Controller и WeatherVisuals добавляют три системы в существующую игру. Новые активности запускаются стандартными ProximityPrompt; сетевой VerityAdventures принимает только Sync/Leave с проверкой аргументов/round/частоты. Навигацией продолжает владеть один TutorialController, отрисовкой — прежний GameplayFeedback RenderStepped. Новые endpoints подключаются неблокирующе. Холодный запуск Studio не выполнялся.

### Погодный цикл

Обновление Fire: ясная погода30с → огненное небо110с → ясно45с → звёздный дождь135с → ясно60с → грозовой ливень95с → радуга/открытая пещера180с → ясно60с. Подробности нового события: docs/FIRE_SKY_WEATHER.md. Цикл повторяется; пауза60с в конце и начальная ясная фаза30с складываются перед следующим огненным небом. Нельзя покупать попытки/шанcы или менять погоду за Robux. После обучения компактная карточка показывает текущее занятие/ожидание; кнопка со стрелкой включает прежний маршрут.

Звёздный дождь: вечернее освещение,48небесных звёзд, до24метеоров с хвостами и три широкие ленты сияния. Игрок начинает поиск у обсерватории погоды на площади и собирает пять разных осколков в персональном порядке среди10точек на тротуарах. Позиции/состояние/награда серверные. Награда — деньги по существующему масштабированию и home_star_mobile. Один успешный грант на UserId/погодный раунд в пределах текущего сервера, включая повторный вход. Повторная выдача декора не создаёт копий.

Грозовой ливень: плотные облака, холодный оттенок, до96полос дождя вокруг игрока,12брызг и редкая дальняя молния. Дождь использует12кэшируемых лучей для поверхностей/крыш, чтобы не продолжать полосы ниже поверхности. Это косметическая гроза, без внезапного урона от молний. Используется прежний разрешённый звук ветра команды, птицы приглушаются через единственный UISoundController; новых аудиоактивов и фоновой музыки нет.

После дождя: большая семицветная радуга над входом, водяная печать становится прозрачнее и открывается обычный prompt входа. В общей физической пещере под картой нужно найти солнечную, лунную и звёздную руны, затем открыть сундук. Есть три предупреждаемых гейзера: жёлтая фаза0,9с до выброса; попадание возвращает к последней руне без потери найденных. На попытку150с, выход доступен всегда, смерть/таймаут/выход чистят попытку. Вход закрывается по окончании погодного окна, но уже начатая попытка может закончиться; закрытие входа не запирает игроков. Награда — деньги и home_rain_relic. Пещера — один общий persistent streaming model, без личных копий и скрытых домашних интерьеров.

### Испытания

Четыре трассы на отдельной террасе за западным краем района, с дорожкой подхода:

- Квантовая трасса: три кольца, засчитываются после фактического серверного рывка.
- Башня титана: три вертикальных кольца10/20/30studs, нужен фактический прыжок титана.
- Небесный слалом: четыре пространственных кольца, требуется реально действующий полёт.
- Призматический тир: три последовательные мишени, засчитываются существующим серверным лазером/наведением/LOS без урона другим игрокам.

Способность должна быть куплена и установлена в нужный слот. Существующий premium-полёт/лазеры принимаются только по реальному владению; тестовые права не выдаются. F/G, L1/R1 и сенсорные кнопки сохранены. Внутри испытания разрешён только нужный слот, остальные занятия блокируются прежним VerityDiversionKind. Лазерный тир — исключение для механизма внутри защищённой тренировочной зоны, а не обход запрета PvP.

Предел попытки65с. Практику можно повторять сразу. Денежная награда по конкретной трассе обновляется через90с и ограничивается по UserId текущего сервера. Любая успешная практика обновляет лучшее время и медаль; поля AdventureRecords добавочно reconciles в прежнем DataVersion2. Хранятся4времени с точностью0,1с; старые профили получают пустой словарь. Дом показывает бронзовый/серебряный/золотой вариант по лучшему времени. Стартовые пороги Gold/Silver: dash4/8с, leap5/9с, flight10/17с, laser17/25с. Эти пороги не подтверждены игровым прохождением.

### Домашние вечеринки

После второго этапа стройки появляется доска у входа. Хозяин выбирает поиск подарков или турнир на автомате; для турнира нужен реально купленный home_arcade. Дом должен быть открыт, дверь автоматически не разблокируется. В районе могут идти4вечеринки, в каждой до6участников; хозяин может играть один. Запись20с, затем поиск подарков100с или турнир240с. Перерыв создания180с по UserId хозяина.

Поиск подарков: шесть подарков в доме в персональном порядке. Достаточно пройти к ним по прежним стрелкам и использовать стандартный prompt. Каждый участник собирает свой набор; чужой подбор не забирает твою цель. Завершение даёт деньги и праздничную звезду. Хозяин/гости не получают прав менять чужой дом.

Турнир: игроки используют существующий серверный30с автомат. Во время турнира он зарезервирован записавшимся участникам; одна завершённая попытка на гостя. Результат берётся из ArcadeService.Finish, не из клиента. Порог праздничной награды100очков. После партии результат остаётся и в прежнем ArcadeBestScore. Три лидера отображаются на доске у дома, приз победителю — home_party_cup. Ничьи разрешаются временем завершения. Закрытие двери/выход/смерть хозяина отменяют вечеринку, очищают участников и занятый автомат. Уже заработанные награды сохраняются, отмена не выдаёт кубок.

### Эффекты и устойчивость

WeatherVisuals владеет только собственными CC/Clouds/декоративным пулом и локальными ClockTime/OutdoorAmbient с сохранением исходного состояния. На выходе восстанавливает свои изменения. Погода сглаженно переходит между состояниями. Обновление декора ограничено20/30/45Гц, единый пул96полос/48звёзд/24метеоров/12брызг/7сегментов молнии/6лент. LowGraphics снижает дождь до16полос, звёзды до16 и метеоры до2; ReducedEffects/ReducedMotion убирают сияние/молнии/быстрые метеоры и сокращают движение. Новый переключатель графики не добавлялся: используется качество Roblox. CC отключается во время существующего показа Verity/награды.

Деньги вычисляются по Activities.Base и серверному множителю. Награды/рекорды меняет сервер один раз, попытки привязаны к живому исходному Character. Выход, смерть, потеря профиля, чужая активность и выход из зоны завершают попытку. Награды хранятся в прежнем CosmeticsOwned,8новых декоративных предметов показываются после второго этапа стройки. Сохраняется staged main.py отдельно от игровых изменений.
