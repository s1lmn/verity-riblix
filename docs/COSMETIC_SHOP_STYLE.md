# Игрушечный каталог украшений

COSMETICS продолжает утверждённый стиль телефона/планшета: кремовый пластик,
фиолетовый корпус, яркие карточки и нативные иконки. CosmeticShopSkin строит
панель/карточки, UIBuilder применяет раскладку. Один прежний ViewportFrame preview
использует VerityFactory/CosmeticFactory. Новые изображения и asset IDs не нужны.

Каталог берётся из Shared.CosmeticCatalog. Сохранены EquipCosmetic и CosmeticPurchase,
серверный inventory и доступность offers, получение реальной цены Marketplace.
Примерка локальная: не запрашивает покупку, не выдаёт ownership; выбранный предмет
помечен, каталог прокручивается к витрине. «Вернуть надетое» применяет настоящий
CosmeticsEquipped. Подпись примерки использует Locale.Bind. Кнопка покупки отключена
без соединения, snapshot, unlock, во время busy и для недоступного предложения.
Core/продукты/receipts не менялись: пока продукт не настроен, предмет только примеряется.

На телефоне/низком landscape всё содержимое прокручивается; touch targets≥44px,
заголовки/названия и длинные кнопки помещаются с переносом. Компактный HUD сохранён,
кнопки используют общий animator и прежнюю обработку Reduced Motion/gamepad.
Новые подписи добавлены в существующий LocaleText для английского языка.

Проверки tools/check_cosmetic_shop.py: исполнение настоящих Skin/Widgets/Controller
с подставными сервисами; export/конструктор/контракт; пять размеров; границы/touch;
owned/equipped/unavailable/busy/offline; настоящая маршрутизация запроса покупки;
примерка/сброс без выдачи владения. Это не реальная Roblox покупка и не Studio render.
Также прошли проверки телефона/планшета, feedback startup, аудио, compile109 Luau
и полная Rojo-сборка. По указанию пользователя Play не запускался.
